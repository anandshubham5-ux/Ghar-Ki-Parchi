# Ghar Ki Parchi

Monthly ration list for the house: pick items by category, set quantities and brands, then tick them off on a kirana-style parchi.

- Works on any phone browser; add it to the home screen to use it like an app.
- The list is saved on each phone. Use **Share → Send parchi to family** to send the same list to someone else.
- Works offline after the first visit.
